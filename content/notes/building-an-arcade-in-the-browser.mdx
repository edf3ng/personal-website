The hard part of a personal site is not the metaphor. It is making sure the
metaphor never gets in the way of the words. Three decisions carried most of
that weight.

## One desktop, windows as routes

The wallpaper and icons live in the root layout. Navigating does not rebuild
the machine; it opens a window. Close it and you are still at the same desk,
with the rain still falling.

<Callout type="tip" title="The cheap version of this">
If you only take one thing from this: put the chrome around the router, not
inside every page. Everything else follows from that.
</Callout>

## Content is a document, not a card

A window should feel like a notebook under a lamp, not a marketing section.
Serif for the file, a soft UI face for the title bar, and a close box that
actually goes home.

## Graphics from elsewhere

I did not draw the icons. Tango already did, in 2005, and released them as
public domain. The wallpaper is a foggy city at night, photographed by
Alex Wong. Borrowing real pictures is how you stop a site from looking
like it was generated yesterday.

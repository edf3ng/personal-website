A fragment shader editor that does the boring parts for you: sets up the quad,
wires the standard uniforms, and recompiles as you type without losing your
scroll position.

## Features

- Live recompile with errors mapped back to the source line
- Auto-generated sliders for every `uniform float` it finds
- Permalinks that encode the whole shader in the URL fragment
- A texture slot that accepts drag-and-drop or a webcam feed

## The interesting problem

Mapping GLSL compiler errors back to editor lines is harder than it sounds,
because the compiler sees a prelude you did not write. The fix was to track the
prelude's line count and subtract it before surfacing anything:

```ts
const PRELUDE_LINES = prelude.split("\n").length;

function mapError(raw: string) {
  return raw.replace(/ERROR: 0:(\d+)/g, (_, line) =>
    `ERROR: line ${Number(line) - PRELUDE_LINES}`,
  );
}
```

Crude, and correct for every driver I have tested.
